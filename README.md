# .github — profils et fichiers communautaires

Ce dépôt contient les éléments partagés par tous les dépôts de l'organisation
**BornToBeFound** :

- `profile/README.md` — page publique de l'organisation ;
- `CONTRIBUTING.md` — méthode de travail commune (branches, commits, PR) ;
- `SECURITY.md` — politique de divulgation ;
- `CODE_OF_CONDUCT.md` — règles de conduite ;
- `SUPPORT.md` — où poser une question ;
- `.github/ISSUE_TEMPLATE/` et `.github/pull_request_template.md` — modèles par
  défaut.

Les dépôts peuvent surcharger ces fichiers ; en cas de divergence, la règle la
plus stricte s'applique et la différence est documentée dans le dépôt concerné.
